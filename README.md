# 💟 Tobii Bonanza Stats (MeguScript)

A tool to handle infos on Tobii Bonanza.

<img width="386" height="338" alt="image" src="https://github.com/user-attachments/assets/ae21ec06-a81e-4391-a6a8-f259a1b05177" />

## ✨ Features
- **Small widget** that shows on Tobii Bonanza site your **current Points/Watched Time** per hourly update.
- Displays **Countdown timer for event end time**.
⠀
## 📋 How to use it?
- Download and install Tampermonkey/Violetmonkey/Greasemonkey.
- Open [tobiibonanzastats.user.js](https://github.com/MeguminShiro/tobiibonanzastats/raw/refs/heads/main/tobiibonanzastats.user.js) and it'll automatically **asks you to install on your previously chosen monkey**.
